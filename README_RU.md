# PDF платы → контуры DXF для Aspire

Конвертер принимает **только одностраничный векторный PDF платы из EasyEDA**. DXF используется исключительно как выходной формат для Aspire: импорт исходного DXF больше не поддерживается, потому что в нём теряется ширина некоторых дорожек и термомостиков.

Из PDF берутся залитые области меди **вместе с их обводкой**, фактическая ширина дорожек и мостиков, контур платы и белые фигуры отверстий. Например, обводка заливки 0,2046 мм расширяет её границу примерно на 0,1023 мм с каждой стороны. На выходе получаются замкнутые DXF-векторы нулевой ширины в миллиметрах:

- `COPPER_OUTLINE_Top-Layer` — границы всей меди, включая дорожки, площадки и мостики;
- `DRILL_OUTLINE` — отверстия, если они присутствуют в PDF;
- `BOARD_OUTLINE` — край платы.

## Графическое приложение без Python

Скачайте `PcbPdfOutline.exe` из [Releases](https://github.com/SolarljodDev/dxf-pcb-outline/releases) или соберите его из исходников (см. ниже). Запустите EXE двойным щелчком. В окне сразу открыты два мини-проводника: слева PDF-файлы, справа папка результата и существующие DXF. Поиск над списками помогает быстро найти файл. Двойным щелчком можно переходить в папки, кнопкой `↑` — на уровень выше; путь можно также вписать вручную. Выберите PDF слева, папку справа и при необходимости измените имя DXF. Галками можно включить или отключить контуры отверстий, контур платы и вычитание отверстий из меди. Затем нажмите «Создать DXF». PDF можно также перетащить в открытое окно.

Если **перетащить PDF на значок EXE**, конвертация начнётся сразу, без открытия основного окна. Готовый DXF появится рядом с PDF с именем `<имя PDF>_fromPDF.dxf`. При повторной конвертации именно этот файл будет перезаписан; одноимённый исходный DXF без `_fromPDF` не затрагивается.

Готовый EXE написан на C# и содержит нужную среду .NET: на компьютере для запуска не нужны ни Python, ни `requirements.txt`, ни установленный .NET. Для пересборки из исходников нужен .NET SDK 8 и доступ к пакетам NuGet:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_portable.ps1
```

Дополнительный запуск через PowerShell (без PDF открывает окно):

```powershell
powershell -ExecutionPolicy Bypass -File .\convert_pdf.ps1
powershell -ExecutionPolicy Bypass -File .\convert_pdf.ps1 "C:\path\board.pdf" -o ".\results\board.dxf"
```

Перед фрезеровкой проверьте масштаб, отверстия и зазоры в Aspire. PDF должен быть одностраничным векторным экспортом платы из EasyEDA.

## Старый вариант на Python

Перетащите PDF на `convert_dxf.bat`. При первом запуске BAT создаст локальное окружение `.venv` и установит зависимости. Файл результата по умолчанию появится рядом с PDF с именем `<имя PDF>_fromPDF.dxf` и будет перезаписан при повторной конвертации.

Или запустите из папки проекта, указав путь результата:

```powershell
.\convert_dxf.bat "C:\Users\bessm\Downloads\PCB_PCB1_2026-10-19.pdf" -o ".\results\PCB_PCB1_2026-10-19.dxf"
```

Для прямого запуска Python:

```powershell
python -m pip install -r requirements.txt
python .\dxf_to_aspire.py "C:\path\board.pdf" -o ".\results\board.dxf"
```

Дополнительные параметры доступны через `python .\dxf_to_aspire.py --help`. В частности, `--no-holes` убирает слой отверстий, `--no-board` — контур платы, `--tolerance` управляет точностью чтения кривых PDF, а `--arc-fit-tolerance` — подбором дуг в DXF. Подбор дуг проверяется против исходных прямых сегментов, чтобы не уменьшать зазоры между дорожками.

PDF должен быть **векторным**, с включёнными слоями меди и сверловки. Зеркальное отражение, поворот, сдвиг и равномерное масштабирование в PDF учитываются при чтении геометрии и ширин линий; перекос и неравномерное масштабирование отклоняются. Если белых фигур отверстий в PDF нет, скрипт предупредит об этом и не сможет восстановить сверловку из изображения или отдельных данных проекта. Перед фрезеровкой сравните DXF с исходной платой и проверьте масштаб и зазоры в Aspire.
